# French practice platform

A privacy-safe static French practice page. It includes an earlier first-steps recap plus practice for reading comprehension, prepositions of place, dates and numbers, pronunciation, browser-local listening, and Unit Zero / Unit 1 preparation on articles, nationalities, hobbies, rhythmic groups, and accents. It collects no student data and uses no external media.

Future learner-facing exercises follow [the authoring standard](AUTHORING_GUIDE.md): natural contexts, one defensible answer, and concise explanations only after a correct answer.

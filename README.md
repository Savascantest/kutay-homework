# French homework notebook

A privacy-safe, static French homework workspace. Each homework has its own tabs, and the archive keeps earlier material available without mixing lessons together. The current homework has 10 grammar questions, 10 vocabulary questions, 5 reading checks, an external three-exercise listening task, and a 10-question final quiz.

Future learner-facing exercises follow [the authoring standard](AUTHORING_GUIDE.md): natural contexts, one defensible answer, and concise explanations only after a correct answer.
